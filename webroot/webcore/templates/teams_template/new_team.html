Instructions

The values are as follows:
Team name : Name of the Team or the group of people.

Describe Team : Describe the functionality of the team and what is there duty.

No. of members: Size of the team or the number of members of the team.

Employee no. : Select the id of the employee to select.

Employee Name : Select the name of the employee to assign the duty.

Site : Select the site you want to provide access for the employee.

Manager : Assign the employee to access all the information under that particular site and manipulate it.

View : Privilege to delete the information on that particular site only.

Write : Privilege to write or add information on that particular site only.

Update : Privilege to update the information on that particular site only.

Delete : Privilege to delete the information on that particular site only.
